# Repository instructions

Read `DESIGN.md` before changing components, documentation, or site copy.

## Product rules

- Keep the registry small and edited.
- Add a component only when it solves a familiar interface problem.
- Use host shadcn tokens in registry components.
- Preserve keyboard, touch, pointer, screen reader, and reduced motion behavior.
- Write plainly. Do not use hype, filler, fake data, fake testimonials, or em dashes.
- Do not leave placeholders, TODO comments, or unfinished examples.

## Required checks

Run `pnpm check` before committing. Run `pnpm registry:build` after changing `registry.json` or a registry component.
